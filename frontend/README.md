# Frontend feature source

`frontend/src/features` chứa scaffold React + TypeScript tương ứng với các thư mục branch FE trong `branches/FE`. Mỗi feature có `feature.config.ts`, `api.ts` và `screen.tsx`. Preview hiện dùng shell ở `src/`; các screen scaffold được nối dần qua router và typed API client theo từng story.
